General

On Android, Firefox freezes tabs that are not on screen, so a site in a hidden tab never finishes its answer. That's why "Automatic" asks one site at a time there: each site's tab comes to the front while it answers.

Site selectors

When a site changes its layout and Ask All can't find the message box, the send button or the answer, fix the CSS selectors here. Each list is tried in order. Tip: on the site, right-click the message box → Inspect, and look for a stable attribute such as data-testid, aria-label or id. Built-in selectors were last researched on .
